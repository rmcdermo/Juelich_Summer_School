# Thermochemistry figures

All images and video posters used by `../../01_thermochemistry.qmd` live directly
in this directory and belong in Git. A checkout can render this section without
the source PowerPoint, extraction folders, or locally generated plots.

## Updating a figure

Replace the descriptive file here, keeping its filename to preserve the QMD link.
For the **Heat release rate in FDS** slide:

- `hrr-fds-flame.png` is the flame visualization. Put the updated flame image here.
- `hrr-fds-comparison.pdf` is the updated time-history plot below it. The slide displays
  `hrr-fds-comparison.svg`, a vector copy of the PDF, and links to the PDF.
  After replacing the PDF, refresh the SVG from the repository root with:

  ```bash
  pdftocairo -svg 08_Combustion/figs/thermochemistry/hrr-fds-comparison.pdf 08_Combustion/figs/thermochemistry/hrr-fds-comparison.svg
  ```
- `arrow-probe-to-plot.svg` is the separate arrow connecting the probe to the plot.

For a new image, put it here, update the QMD reference, and add both to Git.
Commit and push the changes before pulling the repository on another machine.
The table below maps the descriptive filenames to their original extraction names.

## Generated figures and videos

- `burke-schumann-species.png` and `burke-schumann-temperature.png` are generated by
  `../../examples/burke-schumann_example/burke-schumann.py`. Their rendered PNGs are
  versioned so running the example is not required to view the lecture.
- SVG formulas and arrows are standalone versioned images.
- The two videos use GitHub Releases URLs in the QMD. Their poster PNGs are versioned
  here. Local MP4 files are not required.
- `source/` is a local extraction workspace, not a slide dependency. Re-running
  `extract_source_figures.py` writes there and does not overwrite the named figures.

## Provenance

Renaming these files does not change their provenance or licensing status.

- `propane-ball-and-stick.png` is Ben Mills's public-domain
  [Propane-3D-balls-B.png](https://commons.wikimedia.org/wiki/File:Propane-3D-balls-B.png).
- `propane-structural-formula.svg` is a recreated structural formula.
- `cellulose-chains.png` is a rasterization of Laghi.l's
  [Cellulose strand.svg](https://commons.wikimedia.org/wiki/File:Cellulose_strand.svg),
  licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
- `wood-fire.png` was traced to the 2013 *Today I Found Out* article
  [Why Doesn't Wood Melt?](https://www.todayifoundout.com/index.php/2013/08/why-doesnt-wood-melt/),
  which does not identify a reusable image license.
- Other extracted soot, flame, calorimetry, fire-test, equilibrium, FDS, and UMD
  visuals retain the source lecture's provenance. The earlier provenance review
  remains unresolved; this organization change does not establish distribution rights.
