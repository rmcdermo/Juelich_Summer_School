## Setup

This module has two parts:

- **Python**: the exercises in `exercises/` introduce Python, arrays and plotting of FDS device output.
- **HPC**: the slide deck `hpc.qmd` with the examples in `exercises_hpc/` covers running FDS on JURECA.

## How to run quarto

1. https://quarto.org/docs/get-started/

2. type "quarto preview hpc.qmd"
